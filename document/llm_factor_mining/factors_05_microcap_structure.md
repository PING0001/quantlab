# 因子库 E：微盘池结构性因子（MC01–MC30）

> 本池定义：主板流通市值 1-20 亿。此库因子专门刻画"池内相对位置"与微盘特有结构。
> 依据多为 [实践]/[推测]：**没有文献研究过这个特定市值带**，这是本库的最大不确定性。

- **意**: 池内最小市值排名（微盘中的微盘——本池最核心的结构变量）
